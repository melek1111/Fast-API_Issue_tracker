# FastAPI Issue Tracker

A REST API issue tracker built with FastAPI and Pydantic.

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn

## Features

- Create issues
- Get issues
- Update issues
- Delete issues
- Issue priorities

## Running the project

Activate the virtual environment:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install fastapi uvicorn
```

Run the API:

```bash
uvicorn main:app --reload
```

Open the API documentation:

http://127.0.0.1:8000/docs
